# HANDOFF template

Instantiate this **only for substantial or persistent work**. A handoff for a
task that ends inside one session is overhead with no reader.

In this repository the live instance is [`handoff.md`](handoff.md). Its top
section carries this shape; the dated sections below it are the historical
record and are appended to, not rewritten.

Copy from the rule below.
