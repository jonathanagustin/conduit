A Hub owns desired state, approval, artifact admission, and durable history. Spoke agents connect outbound only, execute a leased plan inside an environment, and report what they observe.

The console walkthrough below is the repository demo at `/console/planning`. It shows two profiles: source packaging of Excalidraw at a pinned commit, and application generation from a problem statement. Both are planned, accepted, validated, and handed off as a governed change request. Compute before Accept is refused.

## Choose a starting point

<Tabs>
  <TabItem label="Local demo">

Clone the repository, install the pinned toolchain, and start the demo. When the seed finishes, open the console at `http://127.0.0.1:8081/console/`. Follow [Quick start](/conduit/getting-started/#quick-start).

  </TabItem>
  <TabItem label="Recorded proposals">

Leave `CONDUIT_MODEL_CMD` unset. The Hub keeps the recorded proposals and makes no model call. The variable, and the local command it runs, are described in [Quick start](/conduit/getting-started/#recorded-proposals).

  </TabItem>
</Tabs>
