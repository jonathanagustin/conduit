# Overview contract

`GET /v1/overview` returns one authorization-filtered projection generated by
the Hub. The console refreshes it every 30 seconds and does not assemble the
overview by making independent list calls.

The response carries `generatedAt`, `staleAfterSeconds`, and six panels:

| Panel | Item shape |
| --- | --- |
| `awaitingApprovals` | Change Request ID, title, Environment |
| `failedPlans` | Plan ID, Environment |
| `runningPlans` | Plan ID, Environment |
| `unhealthyEntities` | Environment, installation ID, health |
| `staleReports` | Count only |
| `blockedPromotions` | Promotion ID, Product, version, source channel, target channel |

Each panel has `status`, `count`, and `items`. `CURRENT` means the backing read
succeeded. `UNAVAILABLE` means that panel could not be computed; it must not be
rendered as zero or healthy. At most five items are returned per panel while
`count` retains the authorized total. The current stale threshold is 300
seconds.

The page must distinguish initial loading, request failure, panel
unavailability, and a current empty panel. Item links use the identifiers in the
projection; the browser must not invent missing resource details.

Source anchors: `internal/controlplane/overview.go`,
`web/src/api/overview.ts`, and `web/src/test/e2e/overview.spec.ts`.
