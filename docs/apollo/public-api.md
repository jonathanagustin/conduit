The route table is generated in
[`internal/apollo/routes.gen.go`](../../internal/apollo/routes.gen.go). The
current handler map in
[`internal/controlplane/apollo_api.go`](../../internal/controlplane/apollo_api.go)
binds each operation ID to a handler and enforces operator or Agent identity at
the edge.

Conduit-native extensions use `/v1` routes. They are not added to the public
Apollo document or accepted as extra fields by a public `/api/v0` operation.

## Generation target

The next generator must produce one coherent transport package from the pinned
document:

```text
api-definition.yml
  -> request and response DTOs
  -> strict server interface
  -> client interface
  -> router bindings
```

The adapter implements that server interface and converts generated values to
native commands and queries. A frontend or SDK uses the generated client
interface from the same input. Generated types stop at the adapter; native
contexts keep their own models.

The generation gate must run offline and compare freshly generated bytes with
the committed output. A route count alone is insufficient because it cannot
detect drift in fields, requiredness, enums, unions, errors, or security
requirements.
