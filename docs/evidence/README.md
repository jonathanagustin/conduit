# Repository evidence

This directory contains machine-consumed or immutable evidence retained during
the Conduit extraction. Files here are inputs to tests, candidate-admission
checks, or bounded compatibility claims. They are not general documentation.

Each record keeps its original content so its digest and provenance remain
meaningful. A reference to Palantir in an evidence record identifies the source
or historical observation; it is not Conduit's current repository, package, or
license identity.
